# Discord independent daily participation

Parent ivrm-platform#119, Web economy#621 and runtime#624, Contracts#34/#35. This follows the separately deployed Herta#597 result-card/onboarding slice. No new Bot-side question/answer/ledger database is introduced: existing durable subject-bound daily quiz sessions authorize component submissions; Web remains sole publication, response, scoring, settlement and point authority.

`DAILY_PARTICIPATION_ENABLED=false` by default. When enabled, today's original claim button grants roll-only via v2, then opens the shared question. A second “今日の問題に挑戦” button opens unanswered questions for already-received users without re-claim. Two daily/bonus slots,2/3/4 Button choices, and Modal text input. All subject results Ephemeral; role/Guild/current original Bot announcement/channel/date/window checks remain, along with runtime generation recheck before mutation. Expired/foreign sessions and changed config do not authorize awards. Correct answers never arrive before submission.

Private server-side result card includes separately confirmed streak and first global claim bonus/rank; total never changes old receipt semantics. V1 consumer also parses optional1.2.0 extra, so flag-off Discord results cannot omit a real first award. V2 status/answer/claim validation binds echoed subject, date/receipt, requested question, option/media references and Unicode lengths. Existing saved fortune service/renderer remains in the claim flow.

Question image/audio attachments download from the fixed HMAC media endpoint by media ID, never arbitrary author URL. Streaming bounds10MiB, metadata byte size/type/ID must match, images WebP/audio normalized WAV. They stay private. Web operator owns private100MiB/256-asset cap and rights records; MP3/OGG codecs are not available initially.

Result polling runs **before** the09:00 announcement early return, so closed questions settle after00:00. Web separates result finalization, unique per-user award and outbox. Bot publishes only anonymous votes/proportions/counts, no identities/free text. Deterministic nonce + durable sending/uncertain token + history marker reconciliation + ACK avoid blind resend on restart/Discord timeout. An uncertain result not uniquely found in the last100 messages stays for operator review. Three repeated delivery failures produce a generic no-mention channel warning, rate-limited15min per running process; logs remain if Discord itself is unavailable. No new external paging provider.

Root is sole branch writer; independent read-only review identified/fixed idempotency, safe total, generation/date/question binding and public projection constraints. Focused Bot tests cover signed requests, fail-closed projection, Unicode, already-received flow, stale session/runtime invalidation, midnight and anonymous results. Complete CI and real private cross-client acceptance remain required before release.

Rollback disables Bot participation first, then quiesces Web jobs/flag; retain sessions/claims/responses/results/journal/media. Restore compatible image only. Never reroll, reset or replay an old claim to test a new award. Initial Herta597 card flag may stay enabled independently. No production enablement of this v2 branch yet.
