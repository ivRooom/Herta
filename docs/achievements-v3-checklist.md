# Achievements v3 検証項目

- 既存v2設定を読み込んでも `customAchievements: []` として後方互換化されること
- Custom Series / Stage / ALL・ANY条件を保存できること
- Channel / Role設定がDiscord Pickerで選択できること
- 固定AchievementとCustom Achievementを同時に解除できること
- Custom Achievementの解除通知と報酬Role付与が行われること
- Badge LeaderboardにCustom Badge Pointが反映されること
- Secret Stageが解除前に非表示になること
