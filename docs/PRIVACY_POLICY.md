# プライバシーポリシー(Herta個人データの取り扱い)

このドキュメントは、Discord bot Hertaが収集・保持するメンバーの個人データについて、何を・なぜ・どれだけ保持するかを、実装に合わせて記録するものです。

利用者向けの正本は、いゔる。ーむ公式サイトの[プライバシーポリシー](https://ivrm.jp/privacy)と[利用規約](https://ivrm.jp/terms)です。このドキュメントはその根拠となる実装上の仕様で、Studioの`/privacy`ページはこの内容の要約です。内容を変えるときは、公式サイトの文書(ivRooom/ivrm-web `apps/home/lib/copy/privacy.ts`)とあわせて更新してください。

最終照合: 2026-10-29(`main`のコードと照合。Guildごとのプラグイン有効状態は本番DBを見ていないため対象外)

## 外部への送信

### デイリーボーナスと今日の運勢（β）

有効化されたGuildで本人が操作した場合、Discord本人ID・Guild・対象日・受取状態・共通台帳の受取結果を保存します。ポイントの正本はivrm-webの台帳で、Hertaに独立残高を作りません。Herta側の受取記録（未確定・連携待ち・一時エラーを含む）と占い結果は最終更新から180日、本人専用クイズの回答セッションは1日で削除します。未確定の受取はこの期間内に照合・障害復旧を行います。Herta側の記録削除は共通ポイントの正本台帳を削除・修正しません。

占い履歴には生成結果・対象日・方式のバージョンだけを保存します。誕生日・血液型・MBTIなどのプロフィール原本や、それらの値を含む補足は複製しません。同日最初の結果を使用し、プロフィール変更で再抽選しません。娯楽であり、科学的診断や未来の保証ではありません。

`/herta-privacy export`で本人の受取・占い履歴も取得できます。`/fortune forget`で当該Guildの本人の占い履歴を削除できます。ポイント台帳の削除・訂正は運営へ依頼してください。管理者も許可された範囲だけ閲覧し、プロフィール原本を監査ログへ記録しません。公式Webのプライバシーポリシーとの同時更新・本番受入が完了するまで機能は無効に保ちます。

| 送信先                            | 送信する内容                                                                                                   | 目的                     |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------ |
| OpenAI(API)                       | AI機能:メンション・返信の本文と会話の文脈(Hertaとのやり取り)。VC要約:文字起こし本文と発言者のDiscordユーザーID | 回答・生成物・要約の作成 |
| Amazon Web Services(Transcribe)   | VC文字起こし:同意した本人の発言音声(PCM)をストリームで送信                                                     | 文字起こし               |
| Amazon Web Services(ホスティング) | Herta全体のデータ(データベース・ログ)                                                                          | サービスの運用           |
| Discord                           | Botとしての通常の通信                                                                                          | サービスの提供           |

送信先での保存や学習への利用の有無は、各事業者の規約と運営の契約・設定によります。OpenAI組織のデータ設定と、AWSのAIサービスのオプトアウト設定は、このドキュメントの最終照合時点で確認できていないため、「学習に使われない」とは記載しません。確認後に追記してください。

## 同意の仕組み(VC文字起こし)

- VC発言の文字起こしの対象は、次のいずれかに当てはまるメンバーの発言です。サーバーへの参加や利用規約への同意だけでは対象になりません。
  1. 本人が自分の操作で同意したメンバー(方法は下記)
  2. サーバーの管理者が設定した「自動同意ロール」を持ち、まだ同意・拒否のどちらも選んでいないメンバー
  3. 管理者がStudioの管理画面で同意済みに設定したメンバー(まだ同意・拒否のどちらも選んでいない場合に限る)。この設定はサーバーごとではなくDiscordアカウント単位で保存されるため、Hertaの文字起こしが有効な他のサーバーでも同意済みとして扱われます
- **本人が拒否・取り消しを選んだ場合は、自動同意ロールや管理者の設定に関係なく対象外になります(本人の拒否を優先)。** 拒否は`/herta-privacy voice-consent false`・専用URLで行えます。一度も選んでいない状態で自動同意ロールにより対象になっている場合も、拒否を選べば次の発言から対象外になります。
- 本人の同意の方法は次のいずれかです:
  - `/herta-privacy voice-consent true`コマンド
  - `/vc-recap start`実行時に未同意メンバーへ送られる同意促しメッセージの「同意する」ボタン
  - 同メッセージの「Webで同意する」ボタン、または`/herta-privacy web-link`で発行される専用URL(30分有効)
- 自動同意ロールはDBへ保存しない実行時の判定です。ロールを外すと、次の発言開始時から本人の選択(未選択なら対象外)に戻ります。本人が拒否を記録しているメンバーを、管理者がStudioで同意済みに戻すことはできません。
- 発言開始のたびに最新の同意状態を確認するため、セッション進行中に同意した場合はその時点から対象になります。Discordのコマンド・ボタンでの取り消しは進行中の発言も即座に打ち切って対象外にします。専用URL(Web)やStudioでの取り消しはBotプロセスへ即時通知できないため、取り消し後に新たに話し始めた時点から対象外になります(取り消し操作の瞬間に発言中だった分は、その発言が終わるまで記録される場合があります)。
- 文字起こし本文は、**本文の保存(30日)を説明した上で本人が同意した場合のみ**、セッション終了から30日間保存し、そのサーバーのStudioダッシュボード(VC Recapの閲覧権限を持つ管理者)で閲覧できるようにします。30日を過ぎた本文はworkerが1時間ごとに削除します。本文の保存を説明する前に同意したメンバー、自動同意ロールや管理者の設定で対象になったメンバーの本文は、要約の生成完了時に削除します。以前に同意したメンバーが本文の保存にも同意する場合は、改めて`/herta-privacy voice-consent true`を実行するか、新しい同意促しメッセージ・専用URLから同意してください。
- 要約の生成に失敗した場合は、保存に同意した本人の分を除き本文を削除します。Botの再起動で途中になったセッションは、保存に同意した本人の分も含めて本文をすべて削除します(そのセッションの本文は30日間の閲覧対象になりません)。
- 同意を取り消すと、本文の保存への同意も取り消され、保存済みのあなたの文字起こし本文は即座に削除します。
- `/vc-recap start`実行時、Hertaは必ずそのVCへ「この通話の要約を記録します。同意していない方の発言は記録されません」という趣旨のアナウンスを投稿します。無言での録音は行いません。
- 同意していない参加者の発言は文字起こししませんが、その参加者のDiscordユーザーIDはセッションの参加者記録に残ります(削除依頼で取り除けます)。
- 生の音声データ(録音ファイル)はディスク・データベースのいずれにも保存しません。音声はメモリ上でAWS Transcribeへ送り、テキスト化され次第破棄します。
- **OpenAI音声認識を利用する場合**: 別途OpenAI音声認識が有効化された場合、`/herta-privacy openai-audio-consent true`によって新しい目的・ポリシー版に個別同意した本人の発言音声だけをOpenAI APIへ送信します。旧文字起こし同意・自動同意ロール・管理者操作でこの同意を代替せず、同意がない方は従来のAWS経路に留まります。OpenAIへ送信する音声はメモリ上の一時処理に限り、録音ファイルはHertaに永続保存しません。
- 文字起こし・要約は自動処理のため、聞き取りの誤りや要約の誤りが含まれることがあります。

## データ主体の権利

以下のコマンドを使用できます(Hertaを導入しているサーバー内で実行してください。Slash Commandはサーバーごとに登録されるため、現時点ではDMからは実行できません):

- `/herta-privacy voice-consent <true|false>`: VC文字起こしへの同意を切り替えます。
- `/herta-privacy openai-audio-consent <true|false>`: OpenAIへ生音声を送ることへの**別個の明示同意**を登録・撤回します（OpenAI経路は運営の有効化と本人の新同意が必要）。
- `/herta-privacy web-link`: 同意・取り消し用の専用URL(30分有効)を発行します。
- `/herta-privacy delete-voice-data`: 自分が参加したVC要約・文字起こしデータ(保存中の文字起こし本文を含む)の削除を依頼します。あなた以外に参加者がいないセッションは記録ごと削除します。他の参加者もいるセッションは、あなたの参加記録のみを除去した上で**要約自体も削除します**(要約は複数人の発言から生成された1つの文章であり、あなた由来の内容だけを事後的に取り除くことができないため、他の参加者の分も含めて要約を保持し続けることはしません)。
- `/herta-privacy export`: **VC関連のデータ(同意状態、参加したセッションの要約、保存中のあなたの文字起こし本文)、MBTIの個人履歴、Herta側のデイリーボーナス受取記録と占い結果**をJSONでエクスポートします。活動統計・XP・実績・共通ポイント正本台帳や、その他のプラグインのデータは含まれません。

上記以外のデータ(MBTI個人履歴の削除、活動統計など)の開示・削除は、公式サイトのお問い合わせフォームまたはDiscordのチケットで運営へ依頼してください。

## MBTIの個人履歴

本人が完了した診断の履歴比較のため、サーバーID・本人Discord ID・診断日時・タイプ・Identity・5軸の結果・採点方式を保存します。個人履歴に個別回答やユーザー名を複製しません。履歴は再診断や回答リンクの期限切れでは削除せず、本人からの削除依頼まで保持します。既存の承認済み会員プロフィールには最新のタイプを同期します。

`/mbti-result` は本人にだけ30分有効の閲覧URLを発行します。URLを知っている人も閲覧できるため共有しないでください。再発行すると以前のURLは無効になります。公開用共有URLとPNGは選んだ1回の結果のみで、履歴や本人IDを含めません。匿名の診断統計は個人履歴とは別に、365日の保持方針で蓄積します。Webでの診断の途中データは7日で削除します。

`/herta-privacy export` には、本人の全サーバーのMBTI個人履歴も含みます。閲覧URLのトークンやそのハッシュは含めません。個人履歴の削除は運営者へ依頼してください。
